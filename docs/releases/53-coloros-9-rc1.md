# FCMFix ColorOS 53-coloros-9-rc1

本次为候选版，包含推送路径安全加固和诊断日志优化。包名与签名延续原版，versionCode 升至 61，支持从 53-coloros-8 及其测试包保留数据覆盖安装。安装后请重启手机以加载新模块。

## 日志优化

- 修正系统进程发送诊断广播时未指定 Android 用户而反复出现警告的问题；按宿主权限选择本用户的发送方式。
- 重复诊断日志合并限频，使用单工作线程和有界队列转发，减少推送处理线程上的日志开销。
- 诊断信息先保留本地日志；配置读取失败、解冻失败等关键错误不受新增诊断限频影响。
- `suppressed N diagnostic lines` 表示合并的日志行数，不是丢失的推送数。

## 相比 53-coloros-8 的安全与稳定性调整

- FCM 放行核对真实 GMS 调用者、准确动作、目标包和允许列表，避免普通应用伪造放行请求。
- 修正 Hook 回调与清理逻辑；配置改为不可变快照，配置刷新验证发送者身份。
- 保留每个应用 UID 的 20 秒临时投递窗口，修正并发续期边界。
- Ice Box 激活改为有界后台尽力执行，不再异步重放原系统调用。仍被停用的应用可能错过当前消息，需要后续同步或下一条消息。
- 改进 FCM 组件识别，减少仅包含统计组件时的误判。

## 验证情况与限制

- 日志优化代码已通过 42 项单元测试、Debug/Release lint 和 Release 构建；本次版本另由发布流水线重新验证、签名并附带 SHA256SUMS。
- 同代码的日志测试包已在一加 15 / ColorOS 16 覆盖安装并重启，确认模块加载；所检查的有限日志中未发现新的 FCMFix 异常。
- 普通后台、强停、锁屏消息的完整端到端回归、20 秒窗口边界及普通应用伪造消息测试仍待完成。因此本版标记为预发布，不宣称所有机型、应用或系统版本均已验证。
- 本版没有针对系统界面耗电或 SIM 初始化问题作出修复承诺。日志优化不等于已测得续航改善。

推荐作用域保持原设置。遇到问题请提供机型、完整系统版本、模块版本、目标应用和消息发送时间，以及去除隐私信息后的相关日志。
