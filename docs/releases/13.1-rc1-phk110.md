# FCMFix ColorOS 13.1-rc1-phk110

PHK110（一加 Ace 2 / ColorOS 16 / Android 16）适配构建，基于上游 [13.1-rc1](13.1-rc1.md)（versionCode 80）。

## 相比上游 13.1-rc1

- 保留 PHK110 专属改动（每轮合并重放，上游基于 OnePlus 15 / ColorOS 17 评估未合并，本机 ColorOS 16 实测需要）：
  - 四个 stopped 应用冷启动 hook（`OplusAppStartupManager.shouldPreventStartProcess`、
    `OplusSceneManager.checkReceiverIfRestricted`、`OplusHansManager.isAllowStartService`、
    `BroadcastQueueModernImplExtImpl.skipScheduleReceiver*`），以独立 runHook 分组注册，自检页可见状态
  - FCM 投递窗口 60 秒（上游 20 秒）
- versionCode 81；CI 自签（ci-debug.keystore，与 vc61–vc79 同 key，可直接覆盖安装）。

## 上游 13.1-rc1 带来的主要内容

- **ColorOS 16 hook 兼容修复**（对照一加 15 国行 PLK110_16.0.10.500(CN01) 固件核对，issue #4）：
  - 弱信号联网白名单：C16 无该组件，状态降级为"不适用"（新增 skipped 状态类别），不再误报失配
  - 深睡恢复后 GMS 强停：C16 入口为 `requestSceneAction(Bundle): void`，与 C17 `requestSceneActionSync` 双匹配
  - 电池深睡联网白名单：C16 无 `ControllerCenter.addPkg*WhiteArray`，改 hook 最终管理接口
    `OAppNetControlManager.networkDisableWhiteList(List,int)`，断网名单补入 GMS UID —— 深度睡眠夜间断连的根治路径
- 自检：通知关闭的自动放行应用不再标记为问题。

## 验证

- 安装：`pm install -r` 直接覆盖 vc79（同签名），allowList 保留；**安装后需重启**。
- 重启后：`logcat -s FcmFix` 应见四条 `PHK110 ... hook active`；自检页 Osense/电池名单 hook 显示生效、
  弱信号组件显示"不适用"；深睡断网名单应含 GMS UID（导出报告可查）。
